# Ibnu Zaky — Personal Portfolio Website

A personal portfolio website showcasing the skills, experiences, and projects of **Ibnu Zaky**, a Web Designer & Front End Developer based in Depok, Indonesia. 

🔗 **Live Website:** [https://ibnu-portfolio.netlify.app/](https://ibnu-portfolio.netlify.app/)

## 🚀 Features

- **Modern & Clean UI**: Designed with an eye for aesthetics and usability.
- **Responsive Design**: Looks great and fully responsive on desktop, tablet, and mobile devices.
- **Dark Mode / Theme Support**: Built-in styling for a comfortable viewing experience.
- **Dynamic Projects**: Interactive filter to sort projects by categories (Front End, Apps Design, Team Work).
- **Working Contact Form**: Integrated seamlessly using Netlify Forms.
- **SEO Optimized**: Utilizing proper metadata and semantic HTML.
- **Tools & Blog**: Additional pages for insights, a Web Price Calculator, and an HPP Calculator.

## 🛠️ Built With

- **HTML5 & CSS3** for robust structure and beautiful styling.
- **Vanilla JavaScript** for dynamic interactivity and DOM manipulation.
- **FontAwesome** for scalable and accessible icons.
- **Google Fonts** (Syne & DM Sans) for premium and modern typography.
- Hosted and deployed on **Netlify**.

## 💻 Running Locally

Since this is primarily a static website, you can run it locally with any simple HTTP server. 

1. **Clone the repository:**
   ```bash
   git clone <repository-url>
   cd ibnu-portfolio
   ```

2. **Serve the project:**
   - Using **Python**:
     ```bash
     python -m http.server 8000
     ```
   - Using **Node.js** (via npx):
     ```bash
     npx http-server
     ```
   - Using **VS Code**: Simply install the "Live Server" extension and click "Go Live" from `index.html`.

3. Open your browser and navigate to `http://localhost:8000` (or the port specified by your server).
